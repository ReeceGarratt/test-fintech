# SwiftPay - International Payments

A modern fintech website for fast and cheap cross-border payments. Built with Astro and React for a sleek, contemporary user experience.

## Features

- 🌍 **International Transfers** - Send money to 150+ countries
- 💱 **Real-time Currency Conversion** - Live exchange rates
- 🔒 **Secure Authentication** - Sign up and log in flows
- 🎨 **Dark Theme** - Modern, sleek design with teal accents
- 📱 **Responsive Design** - Works on all devices
- ⚡ **Fast Performance** - Built with Astro for optimal loading

## Pages

- **Home** (`/`) - Landing page with features and CTAs
- **Sign Up** (`/signup/`) - User registration
- **Log In** (`/login/`) - User authentication
- **Transfer** (`/transfer/`) - Currency conversion and money transfer

## Tech Stack

- [Astro](https://astro.build/) - Static site generator
- [React](https://react.dev/) - Interactive components
- [TypeScript](https://www.typescriptlang.org/) - Type safety

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site is configured for GitHub Pages deployment. Push to the `main` branch to trigger automatic deployment.
